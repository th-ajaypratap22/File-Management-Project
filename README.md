# File Management System

A simple Python-based File Management System created to practice File Handling and Exception Handling.

## Features

- Create a file
- Read a file
- Rename a file
- Overwrite file content
- Append content to a file
- Delete a file
- Display available files and folders
- Exception handling for errors

## Concepts Used

- Python
- File Handling
- pathlib
- os module
- Exception Handling
- Functions
- Conditional Statements

## How It Works

The program provides a menu where the user can choose to:

1. Create a File
2. Read a File
3. Update a File
4. Delete a File

The project uses `pathlib` for working with files and folders and `try-except` for handling errors.
